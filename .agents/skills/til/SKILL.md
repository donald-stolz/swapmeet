## Instructions

When invoked, format the user's learning as a concise TIL entry:

**TIL:** [one-sentence summary of what was learned]

**Context:** [brief note on where/how this came up]

**Why it matters:** [one line on when this knowledge is useful next]

If no learning is provided, ask "What did you learn?" and wait for a response.
