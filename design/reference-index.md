## Context

Treat every image in this directory as contextual design evidence from the earlier FigJam exercise.
The screenshots may be original or AI-generated, and their filenames do not carry meaning.

## Workflow

- Inspect every image in this directory and its child directories.
- Inventory each image using its actual relative path.
- Treat images in this directory as the primary direction.
- Analyze `variant-1/` and `variant-2/` as separate directions when those directories exist.

## Goals

- Infer a color scheme with roles for backgrounds, text, accents, borders, and states.
- Infer a typography set with font characteristics, hierarchy, weights, sizes, and practical fallback stacks.
- Infer a button system with variants, borders, radii, spacing, and interaction states.
- Keep this phase limited to colors, typography, and buttons.

## Collaboration

- Label every decision as an observation, inference, or project-owned default. Cite its source image path and confidence.
- Surface conflicts between screenshots. Ask focused questions before combining evidence or choosing a variant.
- Avoid copying logos, trademarks, product names, page wording, or an exact composition.
- After I approve the direction, save the accepted choices in `design-spec.md` beside this file.
- Implement the approved tokens in `client/src/index.css`.
- Do not build pages or components
